# 채점부 (ExamGrader)

> 답만 적으면 되는 시험 채점 기록장

`exam-grader.html` 파일 하나로 동작하는 **단일 파일 웹 앱**입니다. 시험을 여러 번 응시하며 정답과 내 답만 나란히 적어 넣으면 자동으로 채점하고, 회차별 점수 추이·과락 판정·반복 오답까지 기록·분석해 줍니다. OMR 답안지를 옮겨 적듯 쓰면 됩니다.

## 특징

- **설치·서버 불필요** — HTML 파일을 브라우저로 열기만 하면 됩니다. 외부 통신 없음(웹폰트만 CDN 로드).
- **브라우저에 자동 저장** — 모든 기록이 `localStorage`에 남습니다.
- **파일 백업/이동** — JSON으로 내보내고 다시 불러올 수 있습니다.
- **객관식·직접 입력** 두 가지 답안 형식, **다과목 시험**과 **과락/평균 합격 기준** 지원.
- **분석 도구** — 점수 추이 차트, 회차 비교, 문항별 정오 대조, 누적 오답 히트맵.

## 사용법

### 1. 앱 열기

`exam-grader.html`을 웹 브라우저(크롬, 사파리, 엣지 등)에서 엽니다. 더블클릭하거나 브라우저 창에 드래그하면 됩니다.

### 2. 시험 만들기

**+ 새 시험 만들기**(또는 첫 시험 만들기)를 눌러 시험을 설정합니다.

- **시험 이름 / 부제목** — 예: `전기기사 필기`, 부제목은 `2024년 기출` 같은 메모.
- **과목 구성** — 과목명과 문항 수를 지정합니다. **+ 과목 추가**로 여러 과목을 만들 수 있고, 단일 과목이면 이름을 비워도 됩니다.
- **합격 기준(선택)**
  - *과목별 과락*: 해당 점수 미만인 과목이 하나라도 있으면 불합격.
  - *평균 합격 기준*: 과목 점수 평균이 이 점수 이상이어야 합격.
  - 예: 전기기사라면 `40` / `60`. 비워두면 사용하지 않습니다.
- **답안 형식** — `객관식(번호 선택)` 또는 `직접 입력`.
- **선지 개수** — 객관식일 때 2~5지선다.

### 3. 채점하기

시험을 고른 뒤 **채점하기**를 누르면 답안 입력 화면이 나옵니다.

- **응시일 / 메모**를 적습니다.
- 과목마다 **내 답**과 **정답**을 각각 입력합니다.
  - *객관식*: 칸을 클릭한 뒤 **숫자 키를 연달아 누르면** 다음 문항으로 자동 이동합니다. 지우려면 **Backspace**. 방향키로 커서 이동 가능.
  - *직접 입력*: 값을 적고 **Enter**로 다음 칸으로 넘어갑니다.
  - **붙여넣기 상자**에 답을 통째로 넣어도 됩니다. `1 3 4 2 5 …`처럼 공백/줄바꿈/쉼표로 구분하며, `①②③④⑤` 원문자도 숫자로 변환됩니다. 빈칸은 `-` 또는 `0`으로 표시합니다.
- **채점하기**를 누르면 각 문항에 ○/✗가 매겨지고 과목별 점수·평균·합격 판정이 나옵니다.
- **기록에 저장**을 누르면 회차 기록으로 남습니다. (기존 회차는 **수정**에서 열어 **변경 사항 저장**)

### 4. 기록 보기와 분석

- **시험 상세 화면**: 최근/최고 점수, 합격 판정 횟수, 응시 횟수와 **점수 추이 차트**(과목별 선 토글 가능), 회차별 기록 표. 각 회차의 **답안 보기**로 문항별 내 답/정답을 펼쳐 볼 수 있습니다.
- **회차 비교**: 여러 회차를 골라 과목별 점수를 나란히 대조하고, **같은 시험지를 여러 번 푼 경우** 문항별 정오(○/✗)를 비교합니다. *결과가 갈린 문항만* 보기, 모든 회차에서 함께 틀린 문항 표시, **누적 오답 히트맵**(반복해서 틀린 문항)을 제공합니다.

### 5. 백업 / 이동

- 상단 **파일로 내보내기**로 전체 기록을 JSON으로 저장합니다. (시험 상세의 *이 시험 내보내기*는 해당 시험만)
- **불러오기**로 JSON을 가져옵니다. 같은 시험은 회차만 **병합**되고, 새 시험은 추가됩니다.

> ⚠️ 기록은 그 브라우저에만 저장됩니다. 다른 기기로 옮기거나 데이터 유실을 막으려면 주기적으로 내보내 두세요. 사생활 보호 모드/캐시 삭제 시 사라질 수 있습니다.

## 동작 원리

전체가 의존성 없는 **바닐라 JavaScript**로 즉시 실행 함수(IIFE) 안에 담겨 있으며, 파일 하나에 HTML·CSS·JS가 모두 들어 있습니다.

### 데이터 구조

모든 상태는 `localStorage` 키 `chaejeombu.v1`에 JSON으로 저장됩니다.

```
DB = { version: 2, exams: [ Exam, ... ] }

Exam = {
  id, name, subtitle,
  mode: "choice" | "text",   // 답안 형식
  choices: 5,                 // 선지 개수
  cutSub, cutAvg,             // 과락 / 평균 합격 기준 (null이면 미사용)
  subjects: [ { name, count } ],   // 과목 구성(문항 수)
  attempts: [ Attempt, ... ]       // 회차 기록
}

Attempt = {
  id, date, memo,
  subjects: [ { name, count, key[], mine[], correct } ]
  // key = 정답 배열, mine = 내 답 배열, correct = 맞은 개수
}
```

- `load()`가 시작 시 저장본을 읽고, `migrate()`가 옛 데이터(단일 과목·필드 누락 등)를 현재 스키마(version 2)로 보정합니다. 그래서 이전 형식의 기록도 그대로 열립니다.
- `save()`가 변경 때마다 직렬화해 저장하며, 실패 시(저장 불가·용량 초과) 상단 배지를 경고 상태로 바꿔 파일 내보내기를 유도합니다.

### 채점 로직

- 문항별로 정답(`key`)과 내 답(`mine`)을 **공백 제거 + 소문자 비교**로 일치 판정합니다. 정답이 빈 문항은 채점하지 않습니다.
- 과목 점수 = `맞은 개수 / 문항 수 × 100`(100점 환산), **평균**은 과목 점수를 **동일 비중**으로 평균낸 값입니다.
- 합격 판정(`stats()`): `cutSub` 미만 과목이 있으면 **과락**, 평균이 `cutAvg` 미만이면 **기준 미달**, 둘 다 통과하면 **합격**. 기준이 하나도 없으면 판정하지 않습니다.

### 화면 렌더링

- 프레임워크 없이 **상태 → 문자열(HTML) 생성 → `innerHTML` 주입 → 이벤트 바인딩** 방식으로 그립니다. `view` 변수(`exam`/`form`/`grade`/`compare`)에 따라 `render()`가 해당 화면을 다시 그립니다.
- 사용자 입력 값은 `esc()`로 이스케이프해 XSS를 방지합니다.
- 점수 추이 **차트는 인라인 SVG**로 좌표를 직접 계산해 그리며, 격자선·과락/합격 기준선·과목별 보조선·데이터 포인트를 포함합니다.
- **오답 히트맵**은 선택 회차에서 각 문항이 틀린 횟수를 세어 진하기로 표시합니다.

### 입력 편의 기능

- 객관식 그리드는 커서 개념을 두어 숫자 키 입력 시 자동으로 다음 문항으로 이동합니다(`bindGrade`의 키보드 핸들러).
- 붙여넣기(`bulk()`)는 다양한 구분자와 원문자(`①~⑤`)를 파싱해 배열로 채웁니다.

### 파일 입출력

- 내보내기는 `Blob` + `URL.createObjectURL`로 JSON 파일을 즉시 다운로드합니다.
- 불러오기는 `FileReader`로 JSON을 파싱하고, 기존 시험은 회차 ID 기준으로 **중복을 건너뛰며 병합**, 새 시험은 추가합니다. 형식이 맞지 않으면 경고를 띄웁니다.
